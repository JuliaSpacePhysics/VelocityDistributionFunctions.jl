Plasma moments from MMS ion scans

This example computes ion moments from 66 MMS1 FPI burst scans and checks them against PySPEDAS. The fixture holds the raw distribution, the magnetic field and spacecraft potential at the scan times, and the PySPEDAS moments (generated by ref/generate_pyspedas_moments.jl).

using VelocityDistributionFunctions
using Downloads, JLD2

url = "https://github.com/JuliaSpacePhysics/VelocityDistributionFunctions.jl/releases/download/v0.2.1/pyspedas_mms_fpi_brst_i_v2.jld2"
saved = JLD2.load(Downloads.download(url), "result")
dist = saved["dis_dist_brst"]
size(dist["data"])  # (time, φ, θ, energy), phase-space density in s³/cm⁶
(66, 32, 16, 32)

Two FPI properties shape the EnergyAngleBins:

  • FPI angles are instrument look directions, but the bins take particle velocity directions, so both angles are flipped.
  • The azimuth and energy tables change from scan to scan, so the bins are built once per scan.

The bins name the axes of one scan, (φ, θ, energy); the series slices the data along time.

phi = mod.(dist["phi"] .+ 180, 360)
theta = 180 .- dist["theta"]
grid = EnergyAngleBins.(:phi .=> eachrow(phi), :theta => theta, :energy .=> eachrow(dist["energy"]))
moments = plasma_moments(eachslice(dist["data"]; dims = 1), grid; species = :H, units = :df_cm,
    sc_pot = saved["scpot_data"], B = eachrow(saved["mag_data"]))

Temperatures agree with PySPEDAS to rtol = 1e-6. Density, velocity and fluxes differ by about 0.1% because PySPEDAS uses an approximate proton mass, here the CODATA value. The heat flux differs by up to 2% because PySPEDAS evaluates it at bin centers (Heat flux).

ref = saved["ref"]
density = 1e-6 .* moments.density  # m⁻³ → cm⁻³
@assert isapprox(density, ref["density"]; rtol = 2e-3)
@assert isapprox(moments.avgtemp, ref["avgtemp"]; rtol = 1e-6)
(; density_cm3 = density[1:3], density_pyspedas = ref["density"][1:3], avgtemp_eV = moments.avgtemp[1:3])
(density_cm3 = [12.092629471815183, 12.402743720180952, 11.871165411051674], density_pyspedas = [12.105850981450768, 12.41630429408141, 11.88414463864743], avgtemp_eV = [362.26068825857163, 353.0299636107014, 356.5343806940591])
