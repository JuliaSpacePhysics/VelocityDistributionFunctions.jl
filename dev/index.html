VelocityDistributionFunctions.directional_spectra — Method
directional_spectra(S, pitch_angles, loss_cone; half_sector_width, para_tol = 0, perp_tol = 0, method = :mean)

With l = min(loss_cone, 180° - loss_cone), sectors at pitch angle θ are para if θ < l - para_tol, anti if θ > 180° - l + para_tol, perp if l + perp_tol < θ < 180° - l - perp_tol; omni takes all. Sectors with non-finite pitch angle are skipped.

:mean weights sectors by solid angle 2Δθ sin θ, or Δθ sin Δθ within Δθ = half_sector_width of 0° or 180°. The default Δθ is half the median spacing of consecutive finite pitch centers, per scan. :sum does not compensate for skipped sectors.

VelocityDistributionFunctions.gyroaverage — Method
gyroaverage(data, grid, c1 => bins1, c2 => bins2; species, units, B, u = nothing, sc_pot = 0, oversample = 1) -> (; data, volume, edges, centers)

Return the mean phase-space density [s³/m⁶] over the measured part of each bin in the frame moving at u [m/s]. Choose :v_perp and :v_para [m/s], or :pitch [deg] and either :energy [eV] or :speed [m/s], in output axis order. Supply bin edges, or a bin count for pitch. B and u use the input velocity axes. sc_pot [V] corrects detector energies before the frame shift.

volume estimates the sampled velocity-space volume [m³/s³]. Sum data .* volume over finite bins for the measured density [m⁻³]. Each input cell has constant PSD. At zero frame velocity, radial overlaps with energy or speed bins are exact. Other overlaps use sub-cell midpoints, targeting oversample samples per local output bin width (up to 16 per input dimension). Fine bins can receive zero samples even within the field of view.
